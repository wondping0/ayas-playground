# Support

Start with the [README](README.md) and [deployment guide](docs/deployment.md).

- **Bug:** open an issue with reproduction steps, expected and actual behavior,
  environment, and redacted logs.
- **Feature:** explain the problem and a concrete use case.
- **Question:** open a question issue or contact **wondev.support@gmail.com**.
- **Security issue:** email privately; avoid public exploit details or secrets.

The project is maintained on a best-effort basis. There is no guaranteed response
time or commercial support agreement.

An empty local catalog is expected with `AYA_RUNNER=stub`: the stub cannot pass
verification. Use the Docker runner and example seed for the full workflow.

The [public landing](https://wondping0.github.io/ayas-playground/) is a static
introduction, not a hosted checkout or account service.
